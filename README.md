# MyOS
Я пишу операционную систему **MyOS** на **C**. В основном изучаю **Java**, поэтому на ранних этапах активно использую ИИ для навигации по низкоуровневым вещам.

## Цели
- Понять базовую архитектуру ОС (boot → kernel → user space).
- Построить минимальное ядро с управлением памятью и прерываниями.
- Постепенно расширять функциональность (драйверы, файловая система, утилиты).

## Структура репозитория (кратко)
- `boot/` — загрузчик и ранняя инициализация.
- `core/` — ядро и базовые библиотеки.
- `lib/` — дополнительные библиотеки (в будущем).
- `config/` — конфигурации и шаблоны.
