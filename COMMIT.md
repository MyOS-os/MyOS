# Рекомендации по коммитам

Этот файл нужен, чтобы история была понятной и читабельной. Формат свободный, но ниже есть простой стандарт.

## Формат сообщения
```
<тип>: <краткое описание>

<подробности (по желанию)>
```

### Примеры
- `kernel: init basic gdt`
- `boot: add limine config`
- `build: add qemu run target`
- `docs: update build steps`

## Типы изменений
- `boot` — загрузчик, ранняя инициализация.
- `kernel` — ядро (планировщик, память, прерывания и т.д.).
- `lib` — внутренние библиотеки.
- `build` — сборка, скрипты, CI, Docker.
- `docs` — документация.
- `tools` — утилиты, хелперы.

## Рекомендации
- Один коммит = одна логическая задача.
- Сообщение короткое (до ~72 символов), детали — в теле.
- Если правка ломает совместимость — укажи это в теле коммита.
